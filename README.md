# Prism Browser

> Turn hours of research into minutes of reading.

Prism is an AI-powered research browser that automatically gathers information from multiple sources, condenses it into structured knowledge pages, and presents the results in an editable format directly inside the browser.



---

## Problem

When researching a topic, users often:

- Open dozens of tabs
- Read through repetitive information
- Jump between websites
- Struggle to organize findings
- Waste time manually creating notes

Prism simplifies this process by acting as an intelligent research assistant built directly into the browsing experience.

---

## Solution

Prism allows users to:

1. Browse normally
2. Enter a topic or query
3. Select relevant sources
4. Let AI analyze and summarize the content
5. Generate a clean, editable knowledge page
6. Save, modify, and revisit generated content

Instead of reading 20 webpages, users get one structured document containing the most relevant information.

---

## Features

### AI Research Assistant

- Understands user research intent
- Generates focused research plans
- Creates high-quality summaries

### Intelligent Content Extraction

- Extracts content from webpages
- Removes clutter and irrelevant information
- Focuses on key insights

### AI-Powered Summarization

- Condenses large amounts of information
- Eliminates duplicate content
- Produces readable research notes

### Editable Knowledge Pages

- Generated pages can be edited by users
- Add personal notes and changes
- Refine AI-generated content

### Browser Integration

- Built using PyQt6 WebEngine
- Tabbed browsing experience
- Research and browsing in a single application

### Local Project Storage

- Save generated research pages
- Reopen previous sessions
- Organize research efficiently
